## 👋 About Me

I'm a **Senior Software Engineer / Mobile Application Developer** with **4+ years of experience** building high-performance, scalable mobile applications using **React Native, TypeScript, Swift, and modern native technologies**.

I specialize in developing production-ready **iOS and Android applications**, designing scalable architectures, integrating native capabilities, optimizing performance, and shipping features from development to **App Store and Google Play**.

My experience spans **React Native New Architecture, Fabric, TurboModules, JSI, Codegen, SwiftUI, native modules, state management, offline-first applications, testing, and CI/CD**.
